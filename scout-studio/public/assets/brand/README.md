# Robinhood Chain mark

Place the official Robinhood Chain logo here as `robinhood-chain.svg` (square artwork, transparent background).
The badge in the hero, the "Why Robinhood Chain?" block and the footer pick it up automatically; until the file
exists they show a neutral link glyph.

Use only the artwork and usage rules published by Robinhood. Keep the "Independent research" wording and the
non-affiliation line in the footer so the mark is not read as an endorsement.
